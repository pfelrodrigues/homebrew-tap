# homebrew-tap

Homebrew tap for tools by [@pfelrodrigues](https://github.com/pfelrodrigues).

## Install

```bash
brew install pfelrodrigues/tap/macverbs
```

Or, after the tap is present:

```bash
brew install macverbs
```

## Formulas

| Formula | Project |
|---------|---------|
| `macverbs` | [macverbs](https://github.com/pfelrodrigues/macverbs) |

## Casks

| Cask | Project |
|------|---------|
| `grok-bot` | [Grok Bot](https://x.ai/bot) (app desktop; beta, Apple Silicon) |
| `reframed-bridge` | [Reframed Gallery](https://www.reframed.gallery/chrome-extension) (bridge p/ Samsung Frame TV) |
